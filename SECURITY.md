# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.
Instead, report it privately to the maintainers:

- Create a private advisory on GitHub, or
- Send an email to: lucas.sva@outlook.com

I will review and respond to security reports as quickly as possible.
Please give me reasonable time to investigate and fix the issue before disclosing it publicly.

This repository contains synthetic data and infrastructure-as-code samples.
Do not commit real credentials, customer records, or production connection strings.
